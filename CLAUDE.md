# aurora-data-api-proxy

## Language

Everything that lands in the repository is written in English: pull request
titles and bodies, commit messages, code comments, and Markdown files. The
repository is public and already entirely in English, so a Japanese pull
request body would be the odd one out for anyone reading it later.

Chat with the maintainer is a separate matter and can be in Japanese — it is a
conversation, not an artifact the repository keeps.
